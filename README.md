# Jayantrao Mohite — research portfolio

Static GitHub Pages website (no build tools, plugins, or paid hosting required).

## Publish at https://jayant.mohite.github.io/

1. Sign in to GitHub using the GitHub account named `jayant.mohite`. **The domain will only work if that is your actual username**. If the username differs, the free user-site domain will be `https://YOUR-USERNAME.github.io/` instead.
2. Create a **public** repository named exactly `jayant.mohite.github.io` (or `YOUR-USERNAME.github.io` for your actual username).
3. Upload all four files from this folder to the repository root: `index.html`, `styles.css`, `script.js`, `data.json`.
4. Open repository **Settings → Pages → Build and deployment → Deploy from a branch**; choose branch `main`, folder `/(root)`, then **Save**.
5. Visit the appropriate URL after GitHub confirms publishing. The site has not been deployed automatically by this archive.
