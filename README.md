# Jayantrao Mohite Research Portfolio

Static personal research website for GitHub Pages.

## Files
- `index.html` – site structure and content
- `styles.css` – styling and typography
- `script.js` – searchable publications and patents
- `data.json` – publications and patents data
- `hero-sky-earth.png` – hero illustration for the Sky–Earth Convergence theme

## Publish
Upload all files to the root of your GitHub repository and enable GitHub Pages from `main` / `(root)`.
